1. Написати програму, яка оброблятиме список об´єктів класу CHAIR
(стілець). Клас CHAIR повинен мати такі властивості: назва, колір, ціна, 
матеріал. Клас CHAIR повинен мати методи: конструктор класу, зміна ціни.
2. Розробити модуль, який міститиме опис класу Nat (натуральне число), 
що має такі властивості: Value (значення), Divs (список цілих дільників числа). 
Написати для цього класу такі методи: конструктор класу, CalcDivs
(заповнення поля Divs), DisplayValue (виводить саме число), SetValue (змінює 
значення), DisplayDivs (виводить на екран дільники у рядок). В основній 
програмі створити список об´єктів класу Nat, задати їх значення як випадкові 
числа, вивести на екран всі дільники цих чисел.
